WakeUp — Privacy Policy

Effective Date: 2026-04-30

WakeUp ("we," "us," or "the App") respects and protects user privacy. This policy describes how the App handles user data.

1. Data Collection

The App does not collect any user data or transmit it to external servers. Specifically:

  • Camera Images: When the user takes a photo to dismiss an alarm, the image is processed only by Apple's Vision framework on-device. After recognition completes, the image is immediately discarded from memory — never written to disk, never uploaded, never saved, never shared.
  • Personally Identifiable Information (PII): The App does not require account registration; it does not collect names, emails, phone numbers, or any identity information.
  • Location: Not collected.
  • Device Identifiers: We do not collect IDFA, IDFV, or any advertising or analytics identifiers.
  • Usage Analytics: No analytics SDKs (no Firebase Analytics, no Mixpanel, no event tracking).
  • Crash Reports: No crash-reporting services are integrated.

2. Local Storage

The following data is stored only on the user's device and never leaves it:

  • Alarm Settings: Time, label, sound, repeat days, snooze configuration (stored in a local SwiftData database).
  • User Preferences: Default sound, onboarding completion flag, dismissed notification banner tip (stored in UserDefaults).
  • Runtime State: Current alarm's snooze count (stored in UserDefaults, keyed by alarm UUID).

Uninstalling the App deletes all of the above.

3. System Permissions

The App requests the following iOS permissions, each with a clear purpose:

PermissionPurposeImpact if Denied
CameraPhotographing target objects to dismiss alarmsCannot dismiss alarms; App becomes unusable
NotificationsRinging alarms at scheduled timesAlarms do not ring
Time Sensitive NotificationsBypass Focus / Do Not Disturb so alarms reliably ringAlarms may be silenced under Focus modes
Live ActivitiesShow alarm status on Lock Screen and Dynamic IslandLock Screen alarm hint unavailable

4. Third-Party Services

The App uses only the following third-party component:

  • Lottie (airbnb/lottie-ios): Used solely as a local animation rendering library. Does not access the network and does not collect any data.

The App does not integrate any backend services, ad SDKs, analytics SDKs, crash reporting, or third-party login.

5. Data Sharing

We do not share user data with any third party. The App runs entirely offline; aside from requesting iOS system permissions, it makes no network requests.

6. Children's Privacy

The App is not designed for children under 13 years of age. We do not knowingly collect personal information from children.

7. Policy Changes

Updates to this policy ship with new App versions. Material changes will be prominently announced in-app.

8. Contact Us

WakeUp（下称"我们"或"本 App"）尊重并保护用户的隐私。本政策说明本 App 如何处理用户数据。

1. 数据收集

本 App 不收集任何用户数据并发送至外部服务器。具体而言：

  • 相机图像：用户在闹钟响起时拍照，图像仅用于本机 Apple Vision 框架的图像识别。识别完成后，图像立即从内存中丢弃，不写入磁盘、不上传、不保存、不分享。
  • 个人身份信息（PII）：本 App 不要求用户注册账号、不收集姓名、邮箱、电话或任何身份信息。
  • 位置信息：不收集。
  • 设备标识符：不收集 IDFA、IDFV 或其他广告/分析标识符。
  • 使用分析：不接入任何分析 SDK（无 Firebase Analytics、无 Mixpanel、无埋点）。
  • 崩溃日志：不接入崩溃上报服务。

2. 本地存储

以下数据仅存储在用户设备上，不离开设备：

  • 闹钟设置：时间、标签、铃声、重复日、贪睡配置（存于 SwiftData 本地数据库）。
  • 用户偏好：默认铃声、是否完成 Onboarding、是否关闭过通知横幅提示（存于 UserDefaults）。
  • 运行时状态：当前闹钟的贪睡计数（存于 UserDefaults，键名带闹钟 UUID）。

卸载本 App 时，以上数据全部删除。

3. 系统权限

本 App 请求以下 iOS 权限，每项均有明确用途：

权限用途拒绝后的影响
相机拍照识别物品以关闭闹钟无法关闭闹钟，本 App 无法使用
通知在设定时间响铃闹钟不会响
时效性通知（Time Sensitive Notifications）突破勿扰模式以确保闹钟能响勿扰模式下闹钟可能被静音
Live Activities锁屏和灵动岛显示闹钟状态锁屏看不到闹钟提示

4. 第三方服务

本 App 仅使用以下第三方组件：

  • Lottie（airbnb/lottie-ios）：仅作为本地动画播放库使用，不联网、不收集任何数据。

本 App 不接入任何后端服务、广告 SDK、分析 SDK、崩溃上报或第三方登录。

5. 数据共享

我们不与任何第三方共享用户数据。本 App 完全离线运行；除请求 iOS 系统权限外，不发起任何网络请求。

6. 儿童隐私

本 App 不针对 13 岁以下儿童设计。我们不会有意收集儿童的个人信息。

7. 政策变更

如本政策有更新，新版本将随 App 新版本发布。重大变更会在 App 内显著通知。
